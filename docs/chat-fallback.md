# Work制限時のチャット代替

通常のChatGPTから、AI VALUE RADARの公開レポートを再分析し、読者向けの発信素材を作るための代替モードです。

## 使い方

1. [チャット代替ページ](../chat-fallback.html)を開く。
2. 「プロンプトを全部コピー」を押す。
3. 通常のChatGPTで新しいチャットを開き、貼り付けて送信する。

ブラウジングが使えるチャットなら、公開レポートを自動で読み込みます。URLを開けない場合は、取得できなかったURLを明示して、取得できた情報だけで続行する仕様です。必要なら、ダッシュボードの「詳細レポート」を開いて本文をチャットへ貼り付けても構いません。

## 代替できる範囲

- 公開レポートの再分析・再採点
- 読者の困りごと起点の発信ネタ選定
- X / Threads / note / 30秒動画のコピペ用原稿
- Telegram通知相当の短いまとめ
- 公式情報と収益化仮説の切り分け

## 代替できない範囲

- GitHub Actionsの1日4回の自動巡回
- GitHub Actions Secretsの読み取り
- Telegram Bot APIへの自動送信
- ChatGPT画面を閉じた後のチャット処理

この4つは、これまでどおりPublic GitHub + GitHub Actions側が担当します。チャット代替は、Workで作業を続けられないときの「その場の再分析・発信原稿作成」です。

## 判定の考え方

通常の収益候補の条件を無理に緩めません。一方、収益候補がない回でも、読者の悩みと今日の行動が明確なものは「発信候補」または「検証候補」として分けて表示します。公式情報、推測、自分の実利用を混ぜず、公開前に価格・期限・利用条件・PR表記を確認します。
